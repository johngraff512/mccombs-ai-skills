Prompt Pal - Staff

A prompt library and coaching partner for everyday staff work — email, meeting notes, documents, and project planning.

Use it

🔗 Open it in your browsernothing to install

Open Prompt Pal - Staff →

Opens the shared artifact on claude.ai in a new tab. Sign in with your UT Claude EDU account first. Use this if you just want to run it — there is nothing to download.

⬇ Add it to your own AI app~2 minutes, once
  1. Go to claude.ai (or the Claude app) and start a new conversation.
  2. Download prompt-pal-staff.html.
  3. Attach that file to a new message and say: “Create this as an HTML artifact, exactly as-is.”
  4. Claude renders it in the Artifacts panel on the right. From there you can use it live, publish your own shareable link from the “…” menu, or save a copy with the copy/download icons.
  5. To keep it, either bookmark that conversation or use Fork on the artifact to make your own persistent copy.

Prompt Pal - Staff doesn't save chat history between sessions — by design, every session starts fresh, so copy anything you want to keep before you close it.

⚪ ChatGPTNot available — artifacts run on Claude only

Good to know

  • It has to run inside Claude. The chat is powered by Claude's own connection to the Anthropic API, which exists only in Claude's artifact runtime (claude.ai or the Claude app) — opening the .html file straight from your computer shows the interface, but messages won't send.
  • It writes and refines prompts; it doesn't carry out the task the prompt describes. Copy the prompt it gives you into Claude, ChatGPT, or whichever tool you use.

Try saying…

Once the artifact is open, try asking it something like:

“I need a prompt for summarizing these meeting notes into key takeaways and action items.”
“I need a prompt for rewriting this email so it sounds more professional.”
“Here is a draft prompt I wrote — can you coach me on improving it?”

About this artifact

Prompt Pal for Staff is an interactive chat tool that helps university staff write better AI prompts for everyday work. Ask for ready-made prompts for common tasks — cleaning up an email, drafting a professional message, summarizing meeting notes or a report, extracting action items, building a project checklist or timeline, organizing spreadsheet data, outlining a presentation — or paste your own draft and get coached on improving it. Every request returns a basic version, an enhanced version built with the PROMPT framework (Persona, Requirements, Organization, Medium, Purpose, Tone), and a CLEAR check (Concise, Logical, Explicit, Adaptive, Reflective). It only writes and refines prompts — you copy the result into Claude, ChatGPT, or another AI tool to actually run it.
