What's on this site

The catalog holds three kinds of thing. They all make the AI better at a specific job — the difference is how you get to them.

🧩 Skill

A skill is a short instruction file you upload once. After that there is no command to remember — you ask for the task in your own words and the assistant follows the recipe automatically. Most things in this catalog are skills.

When to pick one: Use a skill when you want help with one specific job, like writing a case or building a rubric.

📦 Plug-in

A plug-in packages several skills that work together. Installing it adds all of them at once, and in Claude it keeps itself up to date, so you don't have to re-download when we improve a skill. ChatGPT doesn't support plug-ins — there you upload the skills individually.

When to pick one: Use a plug-in when you want the whole set for a workflow rather than picking skills one at a time.

⚡ Artifact

An artifact isn't installed into the assistant — it's a little web app you open and use, with its own buttons and chat box. You publish the file once in Claude and then just open the link.

When to pick one: Use an artifact when you want a hands-on tool rather than something that answers inside a chat.

You don't need any new software. Everything installs into a tool UT already provides.

Installing, step by step

A single skill, in Claude

  1. On the skill's page in the catalog, click Download <name>.zip. Leave it zipped — don't unzip it.
  2. In Claude, open Settings → Capabilities → Skills.
  3. Click Upload skill and choose the .zip file you just downloaded.
  4. That's it. The skill is now available in every new conversation.

A single skill, in ChatGPT

  1. Download the same .zip from the skill's page.
  2. In ChatGPT, open Skills → Create → Upload from your computer and choose the .zip.

A plug-in (Claude only)

  1. In Claude, go to Customize → Plugins → + → Add marketplace.
  2. Enter johngraff512/mccombs-ai-skills.
  3. Install the plug-in you want. Every skill inside it arrives at once, and it updates itself from then on.

An artifact

  1. Download the artifact's .html file from its page.
  2. In Claude Cowork, add the file to your session and ask Claude to publish this file as an artifact.
  3. Claude gives you a link — open it, bookmark it, and use the tool from there.

Using a skill after you install it

There is no command to type. This surprises most people. Once a skill is installed, you just describe what you want the way you normally would, and the assistant recognizes that the skill applies and follows it.

For example, with the case generator installed, you'd simply write:

“Write a case about Buc-ee's expansion strategy for my MBA operations class.”

Every skill's page in the catalog has a “Try saying…” section with a few real examples you can copy and paste to see it work the first time.

If something doesn't work

I installed it, but nothing seems to happen

Skills activate when your request matches what they're for, so a very short or very general message may not trigger one. Copy an example from the skill's “Try saying…” section — if that works, the skill is installed correctly and it's just a matter of asking with a bit more detail. Also check you're in a new conversation started after you installed it.

Which file do I upload?

The .zip file exactly as downloaded. Uploading a single file from inside it, or a folder you unzipped yourself, won't work.

How do I know when there's a newer version?

Each catalog entry shows a version number and the date it was last updated. Plug-ins installed in Claude update themselves; skills you uploaded by hand don't, so re-download and re-upload when the version changes.

A skill says “Needs local software”

It relies on programs that have to be installed on your own machine, so it can't run on the Claude or ChatGPT websites. Its page explains what's required.
